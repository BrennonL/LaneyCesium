# Directory Contents

This contains the [`lemur-GEOS.czml`](./lemur-GEOS.czml) file. This contains
information about satellite and ground station positions. Also polylines appear
when the lemur satellite comes into view of any of the ground staions. The
packet with the id `prop-35491` contains the time when the GEOS satellite is
in view of the lemur's camera. This is utilized to turn the GEOS satellite
green when this happens.
